👋 DevGuard Tools

Open-source GitHub Actions that catch risky deploys, leaked secrets, and bad migrations before they merge.

Built from real production postmortems — a Flyway migration that locked 6M rows, a docker restart that took a service down for an hour, a .git/ folder leaked to a public host. These tools encode the lessons so you don't learn them the hard way.

Get started

Each tool is a zero-dependency Action. Add one to any repo:

- uses: ivosetyadi/deploy-guard@v1
